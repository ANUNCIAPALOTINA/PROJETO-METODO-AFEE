# Playbooks da agência

Playbooks transformam tarefas repetidas em processos verificáveis.

Cada playbook deve conter:

1. objetivo;
2. quando usar;
3. entradas necessárias;
4. passos;
5. checklist de qualidade;
6. saída esperada;
7. métrica;
8. exemplo aprovado;
9. riscos e limites.

Primeiros playbooks a criar:

- diagnóstico de presença digital;
- calendário editorial;
- roteiro de Reel;
- carrossel de oferta;
- landing page de captação;
- relatório mensal;
- revisão de campanha.
